# Quickstart: 文章评论侧栏（006）

**目的**: 本地验证评论入口、侧栏、发表、点赞、删除与限频。  
**合同**: [contracts/api.md](./contracts/api.md) · **模型**: [data-model.md](./data-model.md)

---

## 前置

1. Postgres 已起：`docker compose up -d postgres`（或等价）
2. 后端：`pnpm run dev:back` → `http://127.0.0.1:4000`
3. 前端：`pnpm run dev:front` → `http://127.0.0.1:3000`
4. 至少一篇**已发布**文章；两个登录账号更佳（作者 A、读者 B）。本地 seed 默认：`author` / `ChangeMe123!`

---

## 场景 A — 浏览侧栏（访客）

1. 未登录打开文章详情  
2. 正文下互动区可见评论入口与数字（可为 0）  
3. 点击评论 → 右侧侧栏打开，标题「评论 N」  
4. 空文显示空态；有评论则较新在上  
5. 关闭侧栏后可继续阅读  

**期望**: 首屏不被评论列表占满；打开侧栏后才见列表加载。

---

## 场景 B — 发表评论（登录）

1. 以读者 B 登录，打开同文侧栏  
2. 输入合法内容（≤1000 字）→ 点「评论」  
3. 新评论出现在列表**顶部**，入口与标题数字 +1  
4. 刷新详情，评论仍在  

**期望**: 未登录点提交会引导登录；空内容被拒。

---

## 场景 C — 发表限频

1. 刚成功发表后，**30 秒内**再发一条  
2. **期望**: 失败提示「请稍后再试」类文案；计数不增加  
3. 等待约 30 秒后再发 → 成功  

---

## 场景 D — 评论点赞

1. 登录后对一条评论点赞 → 数字 +1，已赞态可辨  
2. 再点 → 取消，数字 -1  
3. 未登录可见数字；点击点赞 → 引导登录  

---

## 场景 E — 删除权限

1. 读者 B 删除**自己的**评论 → 成功，计数 -1，刷新不再出现  
2. 读者 B 尝试删他人评论 → 拒绝  
3. 文章作者或 ADMIN 删除该文下任意评论 → 成功  

---

## 场景 F — 图片入口（P3）

1. 打开发表区可见图片相关入口  
2. 点击 → 明确「后续开放/暂不可用」类说明  
3. 文字发表仍可用  

---
