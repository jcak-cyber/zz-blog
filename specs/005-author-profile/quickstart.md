# Quickstart: 个人中心资料（005）

**Feature**: `005-author-profile` | **Date**: 2026-08-14  
**目的**: 手工验证昵称 / 头像 / 简介与公开作者昵称；对照 [contracts/api.md](./contracts/api.md) 与 [data-model.md](./data-model.md)。

---

## 前置

1. PostgreSQL 已启动；后端已应用本功能迁移并 seed。  
2. `pnpm run dev:back`、`pnpm run dev:front`。  
3. 准备一张 ≤2MB 的 JPEG/PNG/WebP，以及一张明显超限或不支持格式的文件（负例）。  
4. 使用已注册账号登录（或先注册再登录）。

---

## 场景 A — 昵称必填与修改

1. 登录后打开 `/author`（手稿台 / 个人中心）。  
2. **期望**：左侧可见昵称；新账号默认昵称 = 用户名；「当前账号」仍为用户名。  
3. 点击「修改昵称」，改为合法新昵称并确认。  
4. **期望**：左侧立即显示新昵称；成功提示；刷新后仍在；用户名不变。  
5. 尝试提交空昵称 → **期望**拒绝，原昵称保留。  
6. 打开首页或任一本人已发布详情 → **期望**作者展示名为**新昵称**（非登录用户名，除非二者相同）。

---

## 场景 B — 头像上传 / 更换 / 删除

1. 个人中心右侧头像区为占位时，上传合规图片。  
2. **期望**：圆形区显示新头像；刷新仍在。  
3. 再上传另一张合规图 → **期望**变为最新一张。  
4. 上传超限或不支持格式 → **期望**中文错误提示，头像不变。  
5. 删除头像 → **期望**恢复占位；刷新后仍无头像；无头像时删除入口不可用或不可见。

---

## 场景 C — 简介显式保存

1. 简介为空时见占位文案（如「这个人很懒…」或等价提示）。  
2. 输入一段文字，**不点保存**，刷新页面 → **期望**仍为空（未持久化）。  
3. 再输入并点击「保存简介」→ **期望**成功提示；刷新后内容仍在。  
4. 输入超过 500 字尝试保存 → **期望**拒绝并提示。  
5. 清空内容并保存 → **期望**恢复空态占位。

---

## 场景 D — 写作入口不受阻

1. 在已展示资料的个人中心，依次点「我的文章」「写新文章」「返回阅读」。  
2. **期望**：行为与改版前一致；登录态保持。  
3. 未登录访问 `/author` → **期望**引导登录，无法改资料。
